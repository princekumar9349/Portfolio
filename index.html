MediSync

AI-Powered Medication Adherence Platform

// The Problem

Medication non-adherence causes over 125,000 deaths annually in the US alone. For elderly and rural patients in India, the challenge is compounded by handwritten prescriptions, language barriers, and no reliable reminder infrastructure.

// What I Built

A full-stack healthcare platform comprising a React Native patient app and doctor app, backed by a FastAPI server. The centrepiece is an AI pipeline that takes a photo of a handwritten prescription and — using Google Gemini Vision + OCR — extracts drug names, dosages, and schedules into a structured JSON medication plan. This plan drives an intelligent reminder engine that sends push notifications, AI voice calls, and caregiver escalation alerts.

// My Contribution

I designed and built the entire system — multimodal LLM prescription parser, FastAPI backend with JWT auth & MongoDB, APScheduler-based reminder engine, Groq Llama-3 multilingual chat, Whisper voice assistant, and the mobile UI. Integrated Firebase for real-time notifications and Google Cloud for deployment.

// Outcome & Impact

Achieved accurate medication schedule extraction from handwritten prescriptions across three languages. Built the full adherence analytics dashboard used by doctors to monitor patient compliance. Platform supports patient-doctor secure messaging and voice-driven queries for elderly users with low digital literacy.

React Native (Expo) FastAPI Python MongoDB Google Gemini Vision Groq / Llama-3 Whisper OpenCV Firebase Google Cloud JWT Auth APScheduler

FasalSathi

AI-Powered Smart Agriculture Platform

// The Problem

Indian smallholder farmers lose 30–40% of crops annually to undetected plant diseases and poor decision-making around crop selection. Existing tools require expensive hardware or agronomist visits that are out of reach.

// What We Built

A smart agriculture platform combining CNN-based plant disease detection (photo → diagnosis + remedy), AI-driven crop recommendation using soil and weather parameters, and real-time weather integration for farming guidance.

// My Specific Contribution

I owned all AI/ML modules: trained and optimised the computer vision disease detection model using TensorFlow/OpenCV, built the crop recommendation engine, designed the FastAPI backend APIs that serve predictions, and integrated real-time weather data pipelines. The React frontend consumed my APIs directly.

// Outcome & Impact

Delivered a functioning platform capable of identifying 15+ common crop diseases from smartphone photos. This project earned us Runner-Up at the Internal Smart India Hackathon 2025, validating both the technical implementation and its real-world applicability for Indian agriculture.
